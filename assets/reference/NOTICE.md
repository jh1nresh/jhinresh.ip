Standalone exports preserve original source silhouettes, textures and source light-theme colors. Browser/notebook/plane are the original inline illustrations; the source has no rocket illustration. Earth is a zero-time frame of the original projection and dither algorithm with a scanline land mask; raster boundary antialiasing can differ from the original Canvas. The original Earth source and land data are also retained for a faithful interactive port.

Original profile-mascot sticker depicts the reference author and is retained only for comparison; use Jerry's own portrait for identity. Steve Jobs artwork is copied unchanged from the MIT repository; book and likeness rights are not separately documented by upstream. No upstream user text, analytics or network calls were added to generated SVGs.

The exports are standalone light-theme SVG images. Parent-page CSS variables and hover styles do not cross an img boundary. Inline copies may use data-mascot-body, data-mascot-face, data-mascot-blink, data-mascot-cheek and data-mascot-hands for local interactions. Each mascot has a distinct filter/clip ID prefix; when inserting two copies of the same mascot inline, suffix its IDs and url references. Navigation paper-cut fills retain explicit color-mix colors supported by current browsers.
